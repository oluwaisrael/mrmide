# Forecaster

Responsive ASP.NET Core Razor Pages recreation of the Forecaster golf analytics landing page.

## Run locally

```bash
dotnet restore
dotnet run
```

Open the local URL printed by ASP.NET Core. The page is implemented in `Pages/Index.cshtml`, with responsive styles in `wwwroot/css/site.css` and mobile navigation behavior in `wwwroot/js/site.js`.
